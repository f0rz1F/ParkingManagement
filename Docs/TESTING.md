# Результати тестування системи (Лабораторна робота 10)

У рамках 10-ї лабораторної роботи проведено комплексне тестування всіх компонентів системи:
1. **MVC веб-панелі адміністратора**: авторизація, збереження кукі, доступ до CRUD.
2. **REST API**: захист ендпоінтів `[Authorize]`, видача JWT-токенів, перевірка хешів паролів через BCrypt.
3. **Дій користувача (Actions)**: отримання списку паркомісць, оформлення нового бронювання, блокування повторного бронювання, скасування бронювання та звільнення місця.
4. **Бази даних SQLite**: перевірка цілісності зовнішніх ключів (Foreign Keys).

## Інструкція для повторного запуску тестів

1. Запустити сервер `ServerApp`:
   ```powershell
   dotnet run --project Server/ServerApp/ServerApp.csproj
   ```
2. У сусідньому терміналі виконати:
   ```powershell
   python Tests/test_system.py
   ```
